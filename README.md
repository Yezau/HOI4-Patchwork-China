# 中国每人一小块地 · Patchwork China

**从一块地起步，成为最后的胜者。**

以中国城市为舞台的架空对局 MOD。
2026 年开局，366 座城市各自为战。选择你的家乡，发展工业、研究科技、组建军队，
逐步扩大自己的地盘。

## 主要内容

- **城市争霸**：366 座城市独立开局，最后存活的势力获胜。
- **发展路线**：多条国策路线与地域特色，搭配内阁、法律和军事建设。
- **科技军备**：完全架空并重新设计的科技、装备与部队编制，
    配套科技中心和各领域研究所。
- **扩张治理**：领土整合、行政压力与部队规模管理，让扩张与建设同样重要。
- **自定义规则**：可调整开局保护期、AI 难度、战争倾向与整合速度等选项。

## 安装

从 [GitHub Releases](https://github.com/Yezau/HOI4-Patchwork-China/releases/latest) 下载安装包。
解压后，将 `PatchworkChina` 文件夹和 `PatchworkChina.mod` 放入 Windows“文档”下的
`Paradox Interactive/Hearts of Iron IV/mod/`，再在启动器播放集中启用。
详细步骤见包内 `INSTALL.txt`。
